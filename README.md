# 📊 E-Commerce Logistics Analytics Dashboard

An end-to-end **Data Analytics & Business Intelligence** project built using **Google Colab (Python + SQLite)** and **Microsoft Power BI**.

This project analyzes an e-commerce logistics dataset to uncover insights into revenue, customer behavior, delivery performance, payment trends, fraud, and product returns through interactive dashboards.

# 📑 Data Preparation & Analysis

Data preprocessing and SQL analysis were performed in **Google Colab**, using **Python (Pandas)** for data cleaning and **SQLite** for SQL-based querying.

The workflow included:

- Cleaning missing and inconsistent values
- Removing duplicate records
- Standardizing categorical data
- SQL analysis using SQLite
- Exploratory Data Analysis (EDA)
- Exporting the cleaned dataset for visualization in Power BI

# 📈 Key Business Insights

- Electronics generated the highest overall revenue.
- Standard customers contributed the largest share of total orders.
- Most deliveries were completed on time.
- Fraud rate remained low, indicating stable transaction quality.
- Clothing products recorded the highest number of returns.
- Urban locations generated the highest order volume.

---

# 💡 Business Recommendations

- Increase inventory for high-performing product categories.
- Improve delivery processes to reduce delayed shipments.
- Investigate return trends for Clothing products.
- Strengthen customer engagement strategies for Premium and VIP segments.
- Continue monitoring fraud patterns to maintain transaction security.
